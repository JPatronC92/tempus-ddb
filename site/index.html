The protocol

A deliberate boundary between intent and effect.

The runtime checks deterministic policy and identity evidence before execution. An executor cannot treat an agent request as authorization; it must consume a valid, bound permit and return a signed outcome.

01 / IDENTITY

Register

Agent identities are recorded with signed registration evidence and lifecycle controls.

02 / POLICY

Authorize

A signed action intent is evaluated against a deterministic, versioned policy bundle.

03 / EXECUTION

Consume once

The executor verifies the permit binding, expiry and tenant before producing an effect.

04 / EVIDENCE

Verify trace

Authorization and execution receipts are linked into a cryptographically verifiable action trace.

In the source

Primitives for bounded autonomous work.

The implementation is a native Rust runtime with Python, CLI and MCP surfaces. The same authorization boundary is used by the generic executor and the constrained GitHub adapter.

Control plane

Policy and identity evidence

Policy decisions bind their digest and reason codes to the issued permit.

  • Ed25519 agent identities
  • Rotation and revocation events
  • Delegation constraints
Execution plane

Fail-closed permit consumption

Single consumption and idempotency protect the handoff from authorization to effect.

  • Short-lived permits
  • Signed executor outcomes
  • Ambiguous effects remain UNKNOWN
Integration plane

Native, CLI and MCP access

Use a local SQLite-backed runtime, inspect its trace, or bind a verified permit to a limited GitHub write.

  • SQLite ledger with WAL
  • Vault Transit signer boundary
  • GitHub issue and pull-request actions

Release boundary

A public beta with its operating limits stated plainly.

v0.4.0 is local-first and designed for a single-instance deployment. Distributed permit consumption, independently durable external checkpoints and a web audit console are not part of the current source line.

Use intentionallyEvaluate the current boundary in a controlled environment before relying on it for production-critical external effects.
